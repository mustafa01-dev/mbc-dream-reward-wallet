# MBC Dream Reward Wallet

A comprehensive reward wallet system with a beautiful landing page and user dashboard.

## Features

- 🎁 Reward tracking and management
- 💳 Digital wallet with balance display
- 📱 Responsive design (mobile-first)
- 🔐 Secure user authentication
- 📊 Transaction history
- 🎯 Reward redemption
- ⚡ Real-time updates

## Quick Start

### Prerequisites
- Node.js 16+
- MongoDB
- Docker (optional)

### Installation

```bash
npm install:all
npm run dev
```

### With Docker

```bash
docker-compose up
```

## Project Structure

```
frontend/     - React/Next.js UI
backend/      - Express.js API
database/     - MongoDB models
```
