# 🚀 Deployment Guide\n\n## Frontend Deployment (Vercel)\n\n### Step 1: Push to GitHub\n```bash\ngit add .\ngit commit -m \"Ready for deployment\"\ngit push origin initial-setup\n```\n\n### Step 2: Deploy to Vercel\n1. Go to [vercel.com](https://vercel.com)\n2. Click \"New Project\"\n3. Import your GitHub repository\n4. Select `frontend` as root directory\n5. Add environment variables:\n   - `NEXT_PUBLIC_API_URL=` (Backend API URL)\n6. Click Deploy\n\n**Your Frontend will be live at:** `https://mbc-dream-reward-wallet.vercel.app`\n\n---\n\n## Backend Deployment (Heroku)\n\n### Step 1: Install Heroku CLI\n```bash\nnpm install -g heroku\nheroku login\n```\n\n### Step 2: Create Heroku App\n```bash\nheroku create mbc-wallet-backend\n```\n\n### Step 3: Add Environment Variables\n```bash\nheroku config:set JWT_SECRET=your_secret_key\nheroku config:set DATABASE_URL=your_mongodb_uri\nheroku config:set NODE_ENV=production\n```\n\n### Step 4: Deploy\n```bash\ngit push heroku initial-setup:main\n```\n\n**Your Backend will be live at:** `https://mbc-wallet-backend.herokuapp.com`\n\n---\n\n## Database Setup (MongoDB Atlas)\n\n1. Go to [mongodb.com/cloud/atlas](https://www.mongodb.com/cloud/atlas)\n2. Create free cluster\n3. Get connection string\n4. Update `DATABASE_URL` in Heroku\n\n---\n\n## Final Steps\n\n1. Update frontend `.env.local`:\n```\nNEXT_PUBLIC_API_URL=https://mbc-wallet-backend.herokuapp.com/api\n```\n\n2. Redeploy frontend on Vercel\n\n3. Test the full stack:\n   - Visit: https://mbc-dream-reward-wallet.vercel.app\n   - Sign up\n   - View dashboard\n\n---\n\n## DNS & Custom Domain (Optional)\n\n**Vercel:** Add custom domain in project settings\n**Heroku:** Add custom domain in app settings\n"
